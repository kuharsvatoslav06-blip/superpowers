# Режиссура озвучки

Голоса не подключены (нет внешнего TTS и записанных дорожек) — структура готова.
Чтобы озвучить реплику: запишите/сгенерируйте файл и назовите его по `id` из таблицы серии, положите в `public/voiceover/<epNN>/`. Тайминг субтитров задаётся в данных серии (`at`/`dur`); если дорожка длиннее — увеличьте `dur` у реплики или сцены.

| Голос | Характер |
|---|---|
| Рассказчик | спокойный, слегка напряжённый; эмоциональнее в ключевых моментах, без театральности |
| Марк | тихий, сдержанный, наблюдательный; недоверчивый тон к незнакомцам |
| Лина | сухой, умный, осторожный; прячет часть правды |
| Джейк | бодрый, общительный, шутит |
| Мия | настороженная, жёсткая, решительная |
| Отец (запись) | спокойный, как завещание |
| ТЕРРА | ровный, «тёплый и пугающий» — без эмоций, но не механический робот |
| Радио | плоский голос диктора сквозь помехи |
