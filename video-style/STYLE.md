# Стиль «ночная инфографика» — шпаргалка

Разбор референсного ролика (576×1024, 30 fps, ~2 мин) и того, как это повторено в `index.html`.

## Формат
- Вертикаль 9:16, логическое полотно 576×1024, экспорт 1080×1920.
- Все функции рисования работают в логических координатах, масштаб задаёт `SC`.

## Палитра
| Роль | Цвет |
|---|---|
| Фон / земля | `#050606` – `#0b0e0e` |
| Рельеф карты | `#1f2923` (тёмно-зелёный, мягкая отмывка) |
| Вода | заливка `#1a3056`, реки `#4a7fc4` со свечением |
| Красная зона | `rgba(94,26,28,.9)` + диагональная штриховка + неоновый контур `#ff6a6a` с размытием |
| Синяя зона / стрелки | `#4d7fd0`, светлый `#8fb8ff`, голова стрелки `#c4dbff` |
| Золото (подзаголовки, акценты) | `#c9a25e` |
| Текст | белый `#f2f2ee`, серый `#9aa3a3`, тусклый `#6b7474` |
| Закат | `#8a6844` → `#a87a4c` (тёплая полоса у горизонта) |
| Ночь | `#070b14` → `#18273d`, свет луны и экранов `#9cc4ff` |

## Типографика
- Заголовок: **Inter Display Black (900)**, 36–40 px, капс («ЭТАП 1», «ВЕСНА 2026»).
- Подзаголовок: Inter Bold 11–12 px, золотой, капс, межбуквенный интервал 2.5–3.5 px.
- Описание: Inter Medium 11 px, серый.
- Подписи на карте: Inter SemiBold 10.5 px, ключевые — Bold 14.5 px. Белая точка для обычного пункта, синий ромб со свечением для «отвоёванного».
- Сноска внизу: 8 px, серый с прозрачностью 70%.

## Композиция кадра
1. **Шапка:** прогресс-бар I–IV (4 сегмента 52×3 px, текущий горит синим), под ним заголовок → золотая строка → серая строка.
2. **Середина:** карта или сцена-силуэт.
3. **Низ:** масштабная линейка + стрелка севера «С», легенда, сноска, при необходимости плашка со счётчиком.
4. Затемнение сверху и снизу (градиенты под текст) + виньетка + лёгкое плёночное зерно.

## Сцены-силуэты (слои снизу вверх)
небо-градиент → свечение солнца/луны → горы (fbm-гребень) → дальний ряд елей → туман → ближний ряд елей → поле со светлой дымкой → силуэты людей/техники (почти чёрные, с тонкой светлой контровой каёмкой) → тёмная земля. Добавки: дым мягкими размытыми клубами, дрон с мигающим красным огоньком, звёзды.

## Анимация
| Приём | Как сделано |
|---|---|
| Переход между сценами | кроссфейд 0.6 с (каждая сцена рисуется в отдельный слой) |
| Появление текста | подъём на 10 px + проявление, easing out-cubic, каскад 0.25 / 0.45 с |
| Печатная машинка | ~11 символов/с, мигающий курсор `▌` |
| Камера карты | медленный зум (логарифмическая интерполяция) и сдвиг, ease-in-out |
| Стрелки | кубическая Безье «прорисовывается», хвост тает в прозрачность, голова светится |
| Удары / акценты | расходящиеся кольца с радиальным свечением, цикл ~1.7 с |
| Изменение территории | граница = базовая линия + гауссовы «вдавливания» по этапам; синяя зона = разница; подписи сами меняются с точки на ромб |
| Счётчик | count-up с ease-out за ~1.1 с, плашка появляется с out-back |
| Параллакс | ряды елей сдвигаются с разной скоростью |
| Шаг путников | синус фазы ног + покачивание корпуса |

## Как использовать
- Открыть `index.html` в Chrome: превью с ползунком.
- Экспорт: `node render.cjs 30 <папка_кадров>` → `ffmpeg -framerate 30 -pattern_type glob -i '<папка>/f*.jpg' -c:v libx264 -pix_fmt yuv420p -crf 20 out.mp4`.
- Свой ролик: правьте массив `SCENES` (каждая сцена — `[длительность, t => {...}]`), `TOWNS`, `PUSH` (как меняется граница по этапам) и тексты.
