# «Кубическая чума» — анимация для YouTube

Готовый ролик: `kubicheskaya_chuma.mp4` (1920×1080, 24 fps, 10:00, H.264 + AAC, громкость −14 LUFS).
Без озвучки и субтитров: сюжет держится на действии, эмоциях, музыке и звуках, как в сценарии.

## Что внутри
- Сцены идут по таймкодам сценария: хук 0:00–0:40, акт 1 0:40–3:00, акт 2 3:00–5:30,
  акт 3 5:30–8:00, акт 4 8:00–9:30, финал 9:30–9:50, конечная заставка 9:50–10:00.
- Стиль взят с рисунков (`source/reference_art.png`): чёрные силуэты стикменов, пиксельный
  кубический мир. Мир стикменов нарисован карандашом на бумаге.
- Мобы (зомби, паук, зелёный шипящий моб, корова) нарисованы в своём стиле, без логотипа
  и без игровой музыки. Пиксель — свой персонаж.
- Звук синтезирован с нуля: пианино, восьмибитные партии, эмбиент, карандашный скрип,
  пиксельный хруст, «пип»-лай, мяу, мурчание, вздохи и «хм?» без единого слова.
- Конечная заставка: превью следующей серии из панелей `reference_art.png` и кнопка подписки.

## Как пересобрать
```
cd source
pip install pycairo numpy
python3 preview.py sheet.png 12 40 300   # контактный лист кадров на заданных секундах
python3 audio.py audio.wav               # музыка и звуки
python3 render.py parts 4                # кадры в 12 кусков H.264
ffmpeg -f concat -safe 0 -i parts/parts.txt -i audio.wav -c:v copy \
  -af loudnorm=I=-14:TP=-1.5:LRA=11 -c:a aac -b:a 192k -shortest kubicheskaya_chuma.mp4
```

Файлы: `engine.py` (рисование, персонажи, оба мира), `common.py` (общие помощники сцен),
`scenes_a.py`…`scenes_d.py` (сцены по актам, там же музыкальные участки и звуковые метки),
`audio.py` (синтез звука), `render.py` (параллельный рендер).
