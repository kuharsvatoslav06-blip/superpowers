# Channel branding

Generated with `node tools/branding.js --name "STICKMAN SURVIVAL" --tag "100 DAYS. ONE STICKMAN. SOMETHING IS ALWAYS WRONG."`
(change the name / tagline and run again). Files land in `build/branding/`.

| File | Size | Where it goes (YouTube Studio → Customization → Branding / Layout) |
|------|------|------|
| `banner.png` | 2560×1440 | Banner image. Text sits inside the 1546×423 safe area, so it is visible on phones, PCs and TVs |
| `avatar.png` | 800×800 | Picture (profile photo), shown as a circle |
| `watermark.png` | 150×150 | Video watermark ("subscribe" button over every video) — display: entire video |
| `endscreen.png` | 1920×1080 | Last 15–20 s of each video; in Studio → Editor → End screen place a video element on each green box and the subscribe element on the circle |

## Channel description
Stickman survival stories in a blocky world. Every episode: 100 days, one stickman, and something that is very, very wrong.
Frozen suns, worlds that remember you, a block that talks... and a mystery that keeps going from episode to episode.

New episode? Watch them in order: Part 1 → Part 2 → Part 3.

Original animation, music and sound effects. Voices: ElevenLabs.
