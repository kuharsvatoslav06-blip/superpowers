# «Что, если Земля остановится на 1 секунду?» — анимационный ролик

Научно-популярный ролик в стиле «What if?»: 1920×1080, 30 fps, ~13,5 минут, русская озвучка,
синхронные субтитры (вшитые караоке-субтитры + отдельная дорожка SRT/VTT), оригинальная
синтезированная музыка и звуковые эффекты. Всё рисуется кодом — статичных картинок нет.

## Быстрый старт

```bash
sudo apt-get install -y rhvoice rhvoice-russian ffmpeg   # голос и кодеки
pip install numpy scipy pillow                           # аудио и утилиты
# Playwright + Chromium должны быть доступны для `require('playwright')`

./build.sh                       # весь фильм  -> build/earth_stops_full.mp4
./build.sh 0 60 build/proto.mp4  # только отрезок (например, прототип первой минуты)
node render.js probe 12 47.5 300 # отдельные кадры для проверки -> build/probe/
```

`build.sh` выполняет: озвучку (`tools/voice.py`) → план сцен и звуковых меток (`render.js plan`) →
музыку и микс (`tools/audio.py`, −14 LUFS) → рендер кадров в 4 потока (`render.js video`) → сборку
MP4 с аудио и дорожкой русских субтитров.

## Как устроен проект

| Файл | Что делает |
|---|---|
| `story.json` | **Сценарий**: порядок сцен, длительность каждой (`dur`), переход (`in`), цветокор (`grade`), настроение музыки, реплики диктора с временем (`at` — секунды от начала сцены). |
| `web/scenes/sNN_*.js` | По файлу на сцену. Каждая сцена — список планов (`SHOTS`) с переходами и функция `cues()` со звуковыми метками рядом с картинкой. |
| `web/lib/stickman.js` | Риг стикменов: позы, походка, бег, мимика (14 выражений), моргание, реквизит. `ALEX` — главный герой, один и тот же облик во всём ролике. |
| `web/lib/env.js`, `set_city.js`, `set_more.js`, `set_rescue.js` | Переиспользуемое окружение: небо, облака, город (с параметрами `chaos` и `ruin`), улица, транспорт, пляж, море, самолёт, мост, аэропорт, поезд, спасательная техника, палатки, краны. |
| `web/lib/globe.js` | Глобус: попиксельная ортографическая проекция текстур, день/ночь, огни городов, облака отдельным слоем (вращаются независимо — этим показана инерция атмосферы). |
| `web/lib/overlay.js` | Субтитры с подсветкой слов, инфографика, плашки, пост-обработка (виньетка, зерно, цвет). |
| `tools/voice.py` | Озвучка RHVoice (мужской голос `aleksandr-hq`), обработка, тайминг слов, экспорт `subtitles.srt/.vtt`. |
| `tools/audio.py` | Музыка (настроения: calm, tension, slowmo, catastrophe, aftermath, emotional, hope, final) и звуки (взрыв, стекло, ветер, шторм, океан, город, сирены и др.), дакинг под голос. |
| `tools/make_earth.py` | Генерация текстур Земли из Natural Earth (public domain). |

## Как редактировать

* **Длительность сцены** — поменяйте `dur` в `story.json`. Все планы внутри сцены растянутся или сожмутся пропорционально; звуковые метки пересчитываются автоматически.
* **Текст диктора** — поменяйте `text`/`at` в `story.json` и пересоберите. Если реплика не помещается, `voice.py` сдвинет её и напишет `WARN`. Реплики, добавленные к исходному сценарию, помечены `"extra": true`.
* **Озвучка ElevenLabs.** Текст для генерации — `voiceover_elevenlabs.txt` (все 41 реплика по порядку, между ними пауза `<break time="1.5s" />`). Готовый файл вставляется командой
  `python3 tools/import_voice.py voiceover.mp3` — она режет запись по паузам на реплики и кладёт их в `voice_override/`. Можно передать и папку с 41 отдельным файлом. Затем `./build.sh`: тайминг субтитров возьмётся из реальной длины записи.
* **Новый план** — добавьте функцию `(ctx, lt, d, t) => {...}` в массив `SHOTS` нужной сцены; переходы: `cut`, `fade`, `whip`, `zoom`, `flash`, `white`, `black`.
